# Citizens Bank - Responsive Landing Page

This project is a responsive landing page developed for the Citizens Bank using HTML5, SASS, and CSS.

## File Responsibilities

1. index.html: The entry point of the application. Uses clean, semantic tags.

2. scss/style.scss: The main entry file that imports all partials.

3. scss/_variables.scss: Global constants for colors, font sizes, and spacing.

4. scss/_mixins.scss: Reusable logic blocks for Flexbox layouts and media query breakpoints.

5. scss/_ui.scss: Styles for common UI components like buttons, inputs, and containers.

6. scss/_mediaquery.scss: Dedicated logic for handling responsiveness across various screen sizes.

7. css/style.css: The compiled CSS file used by the browser.

## Best Practice
1. No Inline Styling: All styles are managed using SCSS for better separation of concerns.
2. Reusable Components: Mixins and variables allow for quick design updates across the entire site.
3. BEM Methodology: Uses BEM naming conventions for predictable CSS behavior.
